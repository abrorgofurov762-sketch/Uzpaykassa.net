# Uzpaykassa — техник тузатишлар қайдномаси

## Mostbet Cash API интеграцияси
- Расмий FAQ асосида HMAC SHA3-256 имзолаш, UTC timestamp ва `X-Project: MBC` қўлланди.
- Cashpoint balance, player lookup, deposit, transaction history, cashout request list ва cashout confirmation методлари қўшилди.
- Депозит фақат провайдер `COMPLETED` статусини тасдиқлаганда муваффақиятли ҳисобланади.
- `NEW`/`PROCESSING` статуслари якуний муваффақият деб кўрсатилмайди; API статуси тарих орқали текширилади.
- Молиявий POST таймаутдан кейин автоматик қайта юборилмайди; ноаниқ натижа оператор текширувига қолдирилади.
- `MOSTBET_LIVE_DEPOSITS_ENABLED=false` хавфсиз стандарт қиймат сифатида қолдирилди.
- Банкка тўланадиган сумма ва букмекерга ўтказиладиган асл сумма базага алоҳида сақланади; эски аризаларда асл сумма бўлмаса автоматик депозит қилинмайди.
- Тўловни бир марта ишлаш учун атомар статус алмаштириш сақланди.
- Cashout API методи мавжуд, аммо у ботнинг ҳозирги картага пул чиқариш жараёнига уланмаган: бу икки жараённинг шартлари фарқ қилади.

## Тестлар
- Автоматик тестлар: 22 та муваффақиятли.
- Синтаксис текшируви: муваффақиятли.
- Тестлар мокланган API жавобларидан фойдаланади; реал пул ҳаракати текширилмаган.

## Реал ишга тушириш чеклови
Mostbet FAQ бўйича sandbox йўқ. API калитлари, касса ҳуқуқи, валюта/лимит ва реал операцияни аккаунт эгаси назоратли кичик суммада текширмагунча интеграцияни ишлаб чиқаришда тасдиқланган деб ҳисоблаш мумкин эмас.

- Фойдаланувчи танловига кўра `.env.example` файлида `MOSTBET_CURRENCY=UZS` кўрсатилди; реал кассада UZS қўллаб-қувватланиши расман тасдиқланмагунча депозитлар ўчирилган ҳолда қолади.
- Депозитдан олдин касса балансида қайтган валюта текширилади; валюта мос келмаса, пулли POST сўрови юборилмайди.
